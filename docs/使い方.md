# 使い方

このツールの操作手順（実行する人向け）。エンジニアでなくてもこのページだけ読めば使えるようにする。

---

## このツールは何をするもの？

soql-collector で作った「SOQL 版レポート」のプログラム（`.py` ファイル）を、
**ダウンローダーに入れる前に、1 本だけ実行して確かめる**ための道具です。

- 本番のダウンロードは「管理表の『SOQL』列が ○」とスケジュールの組み合わせで自動で
  動きます。このツールはその流れを通さず、手動で 1 本だけ試します
- 画面に出るものは 件数・列名・出力先 だけで、**レポートの中身（行の値）は出ません**
- Salesforce への書き込みはしません（読むだけです）

---

## 初回だけやること（1回でOK）

1. **`実行.bat` を1度動かす**（または `python main.py` を実行する）。`config.ini.example` から
   `config.ini` が作られて止まるので、中を開いて値を書き換える

   | キー | 意味 | 書くもの |
   |---|---|---|
   | `DOWNLOADER_ROOT` | ダウンローダーのフォルダ | 隣にある `Salesforceレポートダウンローダー` の場所（相対パス可） |
   | `REPORTS_DIR` | 試す `.py` を置くフォルダ | `./reports`（そのままでよい） |
   | `MASTER_XLSX_PATH` | レポート管理表 | `./input/レポート管理表.xlsx` |
   | `OUTPUT_DIR` | CSV の書き出し先 | `./output`（そのままでよい） |

2. **認証情報を登録する**（Salesforce につなぐため）。`認証情報の登録.bat` を叩く

---

## 毎回の使い方

1. 試したい `.py` を `reports/` に置く（`.gitkeep` 以外は git ignored）
2. ターミナルで `python main.py --list` を叩く。置いたファイルが見つかったか・
   未完成かを見る
3. `python main.py <管理番号> --show` で SOQL の中身を目で確かめる
4. `python main.py <管理番号>` で実行する。`output/` に CSV が出る

引数の書き方:

| コマンド | 意味 |
|---|---|
| `python main.py 1001` | 管理番号 1001 を試す（URL は管理表から拾う） |
| `python main.py 1001 --url https://...` | URL を直接指定する |
| `python main.py reports\sample_report.py --url https://...` | `.py` を直接指定する |
| `python main.py --list` | 一覧を出す（つながらない） |
| `python main.py 1001 --show` | SOQL を表示する（つながらない） |

`実行.bat` を使う場合は `実行.bat` を叩いてから引数を渡します
（`実行.bat 1001` の形）。

## うまくいかないとき

- 黒い画面に赤い英語（エラー名）が出たら、**[ERRORS.md](ERRORS.md)** でその名前を探して対処する
- 「管理番号 1001 のレポート定義がありません」と出たら、`reports/` にファイルが
  置いてあるか、`--list` で管理番号が `KEY` に書いてあるかを確認する
- 「レポート管理表に管理番号 1001 がありません」と出たら、管理表の「ID」列を
  確認する。`--url` を指定すれば管理表を見ずに実行できる
- 解決しないときは、**画面全体をスクリーンショット**して管理者に送る

### 「件数が一致しません」と出たら

SOQL で取った件数と、Salesforce のレポートの総件数が違うという状態です。
**この道具は CSV を書きます**（中身を見るため、件数不一致でも止めない）。
違う原因は SOQL の条件（WHERE）がレポートの絞り込みと違っている等问题です。
レポートの定義と SOQL を突き合わせて直します。

## よくある質問

**Q. 出力ファイルはどこ？**
A. `config.ini` の `[FILES] OUTPUT_DIR` に設定したフォルダに
   `<管理番号>_<日付_時刻>.csv` で出ます（例: `1001_20261102_101530.csv`）

**Q. Salesforce に書き込みますか？**
A. しません。SOQL で読むだけです。
